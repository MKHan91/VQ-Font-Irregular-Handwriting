# Revision experiments: analysis plan fixed before execution

Manuscript electronics-4654524. Written on 11 November 2026, before any of the runs below was executed.
This document is a dated internal record, not a registry entry; in the revised manuscript it is described as
"stated before the runs were executed", not as a pre-registration.

## Common settings

- Stage 2 schedule for every trained arm: configuration file used for the published Stage 2, 41,500 iterations, seed 2
  (additional seeds 3 and 4 only if time allows; if run, all seeds are reported).
- Reference selection: k = 3 references per target from the jamo-overlap mapping, with the evaluated target removed
  from its own reference set (self-excluded mapping). In the folds, references come only from the training part of the fold.
- Folds: 5 folds over the 78 references, stratified by the six structural strata, seed 2026 (sizes 16/16/16/15/15).
  Each held-out glyph is evaluated exactly once.
- Paired metrics on held-out glyphs: PSNR and SSIM with the published protocol (reference converted to 8-bit grey,
  generated image resized to the reference size with Lanczos, data range 255), and LPIPS (AlexNet) at 128 x 128.
- Structural validity (H2): a 3-head jamo-recognition probe (initial/medial/final) trained on the 77 Stage 1 fonts only,
  validated on 18 unseen fonts and on the writer's 78 references, never on any generated image. A glyph is
  structurally valid if all three heads are correct. The probe is frozen before any generated image is scored.

## Arms

## Decision rules

1. H3 (personalization contributes on held-out glyphs): supported if arm A has lower LPIPS and higher SSIM than arm D on
   the pooled held-out glyphs (n = 78), each by a two-sided paired Wilcoxon signed-rank test at p < 0.05.
   If only one metric meets the rule, H3 is partially supported; if neither, not supported. PSNR is reported but not decisive.
2. Ablations: B versus A and C versus A, paired Wilcoxon on LPIPS and SSIM over the same held-out glyphs, Holm-corrected
   over the four tests. A component is called beneficial only if removing it worsens both metrics significantly.
3. H2 (generalization pre-training is necessary): on the full 11,172-syllable inventory generated by the from-scratch model
   trained on all 78 references, H2 is supported if probe structural validity is at least 20 percentage points lower than
   that of the full pipeline, with an exact McNemar test on the paired syllables at p < 0.05. H2 is refuted if the
   from-scratch validity is within 20 points of the full pipeline. Arm F versus arm A on held-out LPIPS/SSIM is reported
   as supporting evidence only.
4. Stage-1-only versus full pipeline on the full inventory: probe validity and the four ground-truth-free indicators are
   reported descriptively, together with the same quantities for the content font and the 78 real references.
5. Everything planned here is reported, including arms that were not run (marked as not run with the reason).
